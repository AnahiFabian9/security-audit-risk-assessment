# Security Controls and Compliance Assessment

## Project Overview

This project involved a simulated security audit of a fictional retail company to evaluate security controls, asset management, and compliance readiness. Using the **NIST Cybersecurity Framework (NIST CSF)** as a reference, I identified security gaps, assessed risks, and documented recommendations to improve the organization's security posture.

**Risk Rating:** 8/10 — High

## 3. Key Findings and Recommendations

Based on the assessment, the following improvements were identified to reduce security risks:

- **Strengthen access management:** Implement least privilege and separation of duties to limit unauthorized access and reduce the risk of misuse.
- **Improve password security:** Establish stronger password requirements and implement centralized password management.
- **Protect sensitive information:** Encrypt payment data and other sensitive information to strengthen confidentiality.
- **Improve asset management:** Maintain an accurate asset inventory and classify assets according to sensitivity and business impact.
- **Enhance threat detection:** Implement an Intrusion Detection System (IDS) to identify suspicious network activity.
- **Establish recovery procedures:** Implement regular data backups and a documented disaster recovery plan.
- **Improve compliance readiness:** Review applicable requirements and strengthen procedures for protecting sensitive information.

## 4. Project Outcome
