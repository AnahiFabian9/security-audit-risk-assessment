# Security Controls and Compliance Assessment

## Project Overview

This project involved a simulated security audit of a fictional retail company to evaluate security controls, asset management, and compliance readiness. Using the **NIST Cybersecurity Framework (NIST CSF)** as a reference, I identified security gaps, assessed risks, and documented recommendations to improve the organization's security posture.

**Skills Demonstrated:** Risk Assessment, Asset Management, Security Controls Evaluation, Compliance Review, Risk Prioritization, and Audit Documentation.

## 2. Compliance Assessment

### Payment Card Industry Data Security Standard (PCI DSS)

| Best Practice                                              | Status |
| ---------------------------------------------------------- | ------ |
| Restrict access to cardholder data to authorized users     | No     |
| Securely store, accept, process, and transmit payment data | No     |
| Implement encryption to protect payment data               | No     |
| Enforce secure password management policies                | No     |

### General Data Protection Regulation (GDPR)

| Best Practice                                                                                 | Status |
| --------------------------------------------------------------------------------------------- | ------ |
| Protect the privacy and security of EU customers' data                                        | No     |
| Maintain a process for notifying affected EU customers of qualifying breaches within 72 hours | Yes    |
| Properly classify and inventory data                                                          | No     |
| Establish and enforce documented privacy policies and procedures                              | Yes    |

### System and Organization Controls (SOC 1 / SOC 2)

| Best Practice                                     | Status |
| ------------------------------------------------- | ------ |
| Establish user access policies                    | No     |
| Protect sensitive personal information (PII/SPII) | No     |
| Maintain data integrity and accuracy              | Yes    |
| Ensure data availability for authorized users     | Yes    |

*Note: These findings reflect the simulated audit scenario and are not an independent certification or formal determination of compliance.*

## 3. Key Recommendations

Based on the assessment, I identified the following improvements to reduce security risks:

* **Strengthen access controls:** Implement least privilege and separation of duties to limit unauthorized access and reduce the risk of misuse.
* **Improve password security:** Establish stronger password requirements and implement centralized password management.
* **Protect sensitive data:** Encrypt payment and other sensitive information to improve confidentiality.
* **Improve asset management:** Maintain an accurate asset inventory and classify assets according to their sensitivity and business impact.
* **Enhance threat detection:** Implement an Intrusion Detection System (IDS) to identify suspicious network activity.
* **Establish recovery procedures:** Implement regular backups and a documented disaster recovery plan.
* **Strengthen compliance practices:** Review applicable requirements and maintain documented procedures for protecting sensitive data.

## 4. Project Outcome

This assessment provided practical experience in evaluating security controls, identifying vulnerabilities, prioritizing risks, reviewing compliance-related practices, and developing actionable recommendations to strengthen an organization's security posture.
